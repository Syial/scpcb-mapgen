Export

Save filters, seed range, and mode as JSON. Results are included when available; query-only works too.

Import

Load a S-Nav search session JSON. Replaces the current filters, range, and results.

Limits

Import also fails when:

  • Not valid JSON, or not a S-Nav search session
  • Unsupported session version
  • Invalid mode, seed range, filters, or results
